# SETHU-CARE Clay Studio™ Design Language v3.0

**Version:** 3.0 Stable
**Purpose:** Master Illustration Specification for AI Image Generation

---

# Introduction

The **SETHU-CARE Clay Studio™ Design Language** is the official illustration system for the SETHU-CARE mobile application.

Every illustration generated using this specification must belong to **one unified illustration library**. Whether generated today, months later, in a new chat, or using a different AI image model, the illustrations should appear as though they were:

* Created by the same 3D artist
* Modeled in the same software
* Rendered in the same scene
* Using the same materials
* Using the same camera
* Using the same lighting
* Following the same design system

**The only thing that changes between illustrations is the subject. Everything else remains identical.**

---

# MASTER STYLE LOCK (Include Before Every Prompt)

Create a premium illustration that belongs to the **SETHU-CARE Clay Studio™ Design Language v3.0**.

This illustration is part of a professionally designed mobile application illustration library. Every illustration in this library shares identical artistic direction, rendering pipeline, geometry language, material response, camera setup, lighting, composition, proportions, and color treatment.

The final image must be visually indistinguishable from every other illustration in the collection except for the subject.

# Camera System

Default camera:

* Isometric 3/4
* Approximately 30° horizontal rotation
* Approximately 20° downward tilt
* Product showcase angle
* Minimal perspective distortion

Never use:

* Front view
* Side view
* Extreme perspective
* Close-up
* Wide-angle
* Dynamic action angles

Exception:

Only map marker illustrations use a top-down camera.

---

# Lighting System

Permanent studio setup.

Key Light

* Upper-left
* Large soft area light

Fill Light

* Gentle front fill

Ambient

* Soft bounce light

Shadow

* One soft contact shadow directly beneath the object

Never use:

* Rim lighting
* Colored lighting
* Dramatic shadows
* Hard shadows
* HDR lighting
* Sunlight

Lighting must remain identical across every illustration.

# Recommended Workflow

1. Generate **welcome.png** first and approve it as the Golden Master.
2. Save it as **style-master.png**.
3. For every future illustration, upload **style-master.png** as a reference image whenever the image model supports reference images.
4. Copy the **Master Style Lock**, append the required **Subject** section, and finish with the **Consistency Lock**.
5. Export every asset as a transparent PNG at **512×512** (or 1024×1024 and downscale for sharper results).
6. Review every new illustration against the Golden Master to ensure camera, lighting, proportions, materials, and color treatment remain visually identical.

Following this workflow produces a cohesive illustration library suitable for onboarding screens, empty states, success states, maps, marketing pages, and future expansion while maintaining a consistent premium visual identity.
