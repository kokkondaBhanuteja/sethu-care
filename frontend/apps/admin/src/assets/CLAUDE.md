# apps/admin/src/assets

Scope: Decorative artwork/illustrations ONLY (interface icons are lucide-react — never files here).
Purpose: The illustration layer of the empty/feature states, per ENGINEERING-STANDARDS Part 6:
Flaticon free-tier artwork is allowed, but every asset MUST be registered below with its author,
source and license, and the aggregate attribution MUST stay visible in Help & support
(adminSettings support.artworkCredit). An unregistered asset fails review.

| Asset | Used for | Source / author | License |
|---|---|---|---|
| table-empty.png | Empty/filtered-empty tables (EmptyState `illustration`) | Product-owner supplied (Flaticon-style clipboard artwork) — confirm author before store release | Flaticon Free (attribution) — assumed |

Boundaries: no interface glyphs; optimize to sensible sizes (<50KB); aria-hidden in use (the
adjacent text carries meaning); update this table + the credits line in the same change as any
new asset.
