# apps/admin/src/assets

Scope: Decorative artwork/illustrations ONLY (interface icons are lucide-react — never files here).
Purpose: The illustration layer of the empty/feature states, per ENGINEERING-STANDARDS Part 6.
**Selected system: Ghozi Muhtarom's "Empty State" lineal-color pack on Flaticon**
(https://www.flaticon.com/packs/empty-state — slate outline + brand-blue accent; matches the
ink/blue token language). Flaticon Free licence: attribution REQUIRED — the visible credit lives in
Help & support (`adminSettings support.artworkCredit`). Every asset is registered here; an
unregistered asset fails review.

| Asset | Used for | Source / author | License |
|---|---|---|---|
| table-empty.png | Genuinely-empty tables (`illustration`/"table") | Product-owner supplied clipboard artwork — confirm author before store release | Flaticon Free (attribution) — assumed |
| filtered-empty.png | "No results for these filters" (`illustration="filtered"`) | Empty Folder — Ghozi Muhtarom, flaticon.com/free-icon/empty-folder_7486767 | Flaticon Free (attribution) |
| empty-box.png | Generic "nothing here yet" (`illustration="box"`) | Empty Box — Ghozi Muhtarom, flaticon.com/free-icon/empty-box_7486744 | Flaticon Free (attribution) |

Boundaries: one author pack per state family (Ghozi Muhtarom lineal-color for admin states); no
interface glyphs; optimize to ≤256px/≤50KB; aria-hidden in use; update this table + the credit
line in the same change as any new asset.
